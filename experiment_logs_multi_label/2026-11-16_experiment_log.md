2026年11月16日 日本時間。抗酸化・抗菌・毒性の3活性を同時に予測するmulti-label実験に向け、データを再集計し、6種類のモデルのコードを追加した。既存のCNN・Random Forest・LightGBMと合わせて9モデルを共通の学習・評価処理から呼び出せる構成とした。

本作業ではESM-2の新規推論と実データによる分類モデルの学習を実行していない。したがって、新しいmulti-label実験の性能値や学習結果はまだない。今回のログはデータの確認、コードの準備、今後の計画を記録する。

## 入力データの構造

入力はdata/multi-label.csv。列の順序はsequence、antioxidant、antimicrobial、toxicで固定する。ラベルベクトルは抗酸化、抗菌、毒性の順である。

```
sequence,antioxidant,antimicrobial,toxic
EL,1,1,0
FLKPLFNAALKLLP,1,1,1
```

1は対応する元データに活性の記載があることを表す。0は記載なしで、陰性または未知を含む。現段階では0を学習上の陰性として扱うため、実験で陰性が確認されたことは意味しない。ベクトルを10進数の1クラスには変換しない。

## 学習モデルのコード構成

入口はmain_multi_label.py、各モデルの関数はmulti_label_pipelineに置く。--modelsで選択し、指定しなければ下記9モデルが対象となる。特徴量抽出や学習の実行は今後行う。

| モデルと選択名 | 実装と初期設定 |
| --- | --- |
| CNN  cnn 既存 | 特徴量方向の1次元畳み込み、3出力logit、BCEとSigmoid |
| Random Forest  rf 既存 | 活性別の二値分類器、300本、balanced_subsample |
| LightGBM  lightgbm 既存 | 活性別の二値分類器、300本、学習率0.05、balanced |
| Logistic Regression  lr 追加 | 標準化、L2正則化、C=1、活性別の二値分類器、balanced |
| MLP  mlp 追加 | 全結合1280→256→64→3、GELU、Dropout 0.3、BCEとSigmoid |
| Classifier Chain  chain 追加 | 標準化とLRを連鎖、順序0→1→2、内部3分割CVの予測を利用 |
| CatBoost  catboost 追加 | ネイティブMultiLogloss、300反復、深さ6、学習率0.05、重みなし |
| XGBoost  xgboost 追加 | 活性別binary:logistic、300本、深さ6、学習率0.05、hist |
| SVM  svm 追加 | 標準化、RBF、C=1、gamma=scale、balanced、確率出力あり |

各活性の確率を個別に出力し、3確率の合計を1にそろえない。既定の判定閾値は各活性0.5で、000や111の予測も可能とする。SVMもSVC.predictではなく、推定確率に共通の閾値を適用して評価する。

CNNとMLPは学習データ内の約20%を内部検証に使い、最大30エポック、patience 5で回数を選ぶ。選んだ回数で外側の学習データ全体から新しいモデルを学習する。標準化と陽性重みの計算も学習側だけで行う。

Classifier Chainの各リンクでは、内部CVで得た予測を次のラベルの入力に使う。推論時は前のリンクの予測を順番に使う。既定の順序は抗酸化→抗菌→毒性。ラベルの共起には収集や注釈の偏りも含まれるため、生物学的な因果関係とは解釈しない。

XGBoostは各活性の学習側の陰性数／陽性数をscale_pos_weightに使う。CatBoostは今回、重みなしのMultiLoglossを使う。モデルごとに不均衡への対処が異なるため、各設定を保存して比較する。SVMの確率推定には追加の学習時間がかかる可能性がある。

## これからの実験計画

1  ESM-2の新規特徴量抽出を実行する。モデルはfacebook/esm2_t33_650M_UR50D、最終33層の残基表現を平均し、BOS・EOS・paddingを除く。1配列から1,280次元を得る。予定する出力はXが(7963, 1280)のfloat32、yが(7963, 3)の0/1行列である。

2  抽出結果の配列、ラベル順、件数、元データ位置を確認する。NPZにはX、y、sequences、source_rows、label_names、taskを保存し、抽出条件と除外一覧も保存する。

3  共通の分割でモデルを比較する。seed 42、iterative stratification、独立テスト約10%を予定する。現在の入力で分割だけ確認すると、CV用学習7,176件、独立テスト787件（9.88%）となる。これは計画の確認であり、学習結果ではない。

4  学習データの共通5分割CVで9モデルを比較する。設定、Chainの順序、閾値を調整する場合は学習側だけを使い、必要に応じて内部CVを置く。独立テストの性能を見て設定を選ばない。

5  設定を確定したモデルを学習データ全体で学習し直し、独立テストで評価する。同一配列は両集合に重複させない。現在は同じ収集元から分けたテストであり、類似配列のクラスタ分割や別取得元による外部検証は今後の検討項目とする。

## 評価指標と作成予定の図

活性別にROC-AUC、Average Precision、Sensitivity、Specificity、Precision、F1、MCC、TP・FN・FP・TNを記録する。全体はMicro／Macro F1、Hamming loss、Subset Accuracy、Binary Log Lossなどを比較する。計算できない指標は0で埋めず空欄またはnullとする。
